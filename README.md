# 💳 Credit Card Financial Dashboard

An interactive  **Credit Card Financial Dashboard** built using **Power BI, SQL, Power Query, and DAX** to analyse credit card revenue, customer spending patterns, transaction trends, and key business performance metrics. The dashboard provides stakeholders with actionable insights to monitor operations and support data-driven decision-making.

---

## 📌 Business Requirement

The objective was to develop a comprehensive **weekly credit card dashboard** that provides stakeholders with visibility into key performance metrics, transaction trends, customer behavior, and overall credit card operations.

The dashboard enables business teams to:
- Monitor weekly performance metrics
- Identify customer spending patterns
- Analyze transaction trends
- Make data-driven business decisions

---

## 🛠️ Solution Developed

Developed an interactive **Power BI dashboard** using customer and transaction data.

### Key Features:
- Cleaned and transformed raw data using Power Query
- Created DAX measures and KPIs to track business performance
- Analysed revenue, transaction amount, and transaction count
- Built customer segmentation analysis based on age, income, education, occupation, and card category
- Designed interactive reports with slicers, filters, and drill-down capabilities
- Delivered actionable business insights through intuitive visualisations

---

## 📊 Dashboard Insights

- Weekly revenue and transaction performance tracking
- Customer spending behaviour analysis
- Revenue analysis by expenditure type
- Revenue by customer demographics
- Card category performance comparison
- Credit card usage analysis (Swipe, Chip, Online)
- Quarterly revenue and transaction trends
- State-wise customer revenue analysis
