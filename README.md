# 💳 Credit Card Financial Dashboard

Interactive **Credit Card Financial Dashboard** built using **Power BI and SQL** to analyze revenue, customer spending patterns, transaction trends, and key business KPIs.

---

## 📌 Business Requirement

The objective was to develop a comprehensive **weekly credit card dashboard** that provides stakeholders with visibility into key performance metrics, transaction trends, customer behavior, and overall credit card operations.

The dashboard enables business teams to:
- Monitor weekly performance metrics
- Identify customer spending patterns
- Analyze transaction trends
- Make data-driven business decisions

---

## 🛠️ Solution Developed

Developed an interactive **Power BI dashboard** using customer and transaction data.

### Key Features:
- Cleaned and transformed raw data for reporting analysis.
- Created KPIs to track credit card performance.
- Analyzed revenue, transactions, customer segments, and spending trends.
- Designed interactive charts, filters, and dashboards for better insights.
- Generated actionable insights to support stakeholder decision-making.

---

## 📊 Dashboard Insights

- Weekly revenue and transaction performance tracking
- Customer spending behavior analysis
- Credit card usage pattern analysis
- KPI monitoring for business performance
- Trend analysis for better decision-making
